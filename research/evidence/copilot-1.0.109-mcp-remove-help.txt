Usage: copilot mcp remove <name>

Remove an MCP server from the user configuration.

Only servers in the user configuration (~/.copilot/mcp-config.json)
can be removed. Workspace servers must be removed from their
respective config files. Plugin servers must be uninstalled.

Arguments:
  <name>
          Server name

Options:
  -h, --help
          Print help (see a summary with '-h')

Examples:
  # Remove a server
  $ copilot mcp remove github
