# R8. Glossary and topic index

| Term | Meaning in this manual | Reference |
|---|---|---|
| Approval | A decision granting a defined action or scope; its effect depends on the active permission mode. | [S1](../security/01-permissions-isolation.md) |
| Autopilot | A documented CLI continuation mode; separate from broad tool permissions. | [A1](../agents/01-supervised-autonomy.md) |
| Checkpoint | A durable, reviewed record of task state and evidence. | [X2](../context/02-context-lifecycle.md) |
| Compaction | Summarization of session context that can omit detail. | [X2](../context/02-context-lifecycle.md) |
| Connector | A connection to external service tools; availability and preview status can vary. | [E1](../extensions/01-mechanisms.md) |
| Custom agent | A specialized profile with instructions and tool configuration. | [A2](../agents/02-custom-agents.md) |
| MCP server | A provider of external tools or data through Model Context Protocol. | [E1](../extensions/01-mechanisms.md) |
| Marketplace | A catalog through which plugins can be discovered. | [R4](extensions.md) |
| Plugin | A distributable package of one or more customization components. | [E2](../extensions/02-lifecycle.md) |
| Sandbox | An isolation mechanism with a particular scope, backend and policy; not a universal guarantee. | [S1](../security/01-permissions-isolation.md) |
| Skill | Task-specific instructions and optional resources. | [E1](../extensions/01-mechanisms.md) |
| Subagent | A separately contextualized agent used for a delegated portion of work. | [A2](../agents/02-custom-agents.md) |
| Task contract | An agreed goal, scope, constraints, acceptance criteria and approval boundaries. | [X3](../context/03-task-contracts.md) |
